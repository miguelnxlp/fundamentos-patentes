Análisis Estructural

¿De qué documentos se compone una solicitud?

La estructura es fundamental para determinar el alcance de la protección. Analicemos el siguiente caso práctico.

1. El Título de la Invención
VEHÍCULO Y MÉTODO DE MEDICIÓN PARA REGULACIÓN DE CATENARIA TRANVIARIA Y MORDAZA PARA RIEL
2. Resumen / Descripción del Invento
Esta invención incluye un vehículo que se mueve sobre un solo riel (como un monorriel) diseñado para ajustar los cables eléctricos que alimentan a los tranvías. También tiene una herramienta especial que se agarra al riel, y un método para medir y asegurarse de que el cable eléctrico esté a la altura correcta para que los tranvías funcionen bien.

3. Las Reivindicaciones

Estructura

Las reivindicaciones definen el perímetro legal de la invención. Se construyen en tres partes fundamentales:

1. Preámbulo: Coincide con el título (aparato, proceso, etc.)
2. Enlace gramatical: "caracterizado por", "que comprende"
3. Parte Característica: Características técnicas nuevas
Ejemplo Aplicado:
1. Un vehículo (100) tipo monorriel para regulación de catenaria tranviaria que comprende : - un chasis (110); - una mordaza para riel (200) conectada al chasis (110) y a un riel (1), - donde la mordaza para riel (200) incluye un mecanismo de apertura y cierre (220) con un elemento de agarre (226) que se acopla al riel (1)

Nota de Advertencia de Privacidad

Se recomienda que para trabajos reales correr el modelo generativo localmente, y no permitir que la información entre a una nube o repositorio público para evitar destruir el requisito de novedad.

Terminal de Prompting para Patentes
Primer paso: Modelo

Escoger el modelo de IA generativa que este de acuerdo a su plan o si tiene acceso gratuito (Ej. ChatGPT, Claude, Llama local).

Segundo Paso: Elementos del Prompt
  • ROL: ¿Quién es la mejor persona para redactar una patente?
  • CONTEXTO: ¿Cuáles son las circunstancias de modo, lugar, tiempo, legislación que debería tenerse en cuenta para hacer una adecuada redacción?
  • INSTRUCCIÓN: ¿Qué se le va a pedir al modelo?
  • DOCUMENTOS: Cuáles documentos pueden dar un contexto. Una vez definidos agréguelos al Chat, Agente o Notebook.
Tercer Paso: Escoger una invención para el ejercicio
Opción 1

Wearables y Biometría

Dispositivos inteligentes (relojes, pulseras) que no solo monitorean la salud, sino que se integran con el estilo personal.

Opción 2

Tejidos Inteligentes

Ropa con tecnología funcional, como tejidos que no se manchan, antibacterianos (anti-COVID) o interactivos.
